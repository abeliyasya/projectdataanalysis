# Data Analysis Projects

### 1. Analisis dan Prediksi Churn Pelanggan
- **File:** `Analysis_Churn_by_Abel.ipynb`, `ML_Churn_LightGBM.ipynb`
- **Dataset:** `Churn.csv`
- **Tujuan:** Mengidentifikasi faktor-faktor yang memengaruhi pelanggan berhenti berlangganan, lalu membangun model machine learning untuk memprediksi pelanggan yang berisiko churn sehingga perusahaan dapat melakukan retensi lebih awal.
- **Tools:** Python (pandas, matplotlib, scikit-learn, LightGBM)
- **Temuan utama:**
  - Tingkat churn keseluruhan sebesar **20.37%**.
  - Faktor yang paling berpengaruh terhadap churn: **Geografi & Gender, Usia, dan Keaktifan nasabah**.
  - Model LightGBM mencapai **accuracy/AUC/recall sebesar 0.88**.

### 2. Analisis Penjualan Kopi Nang Kau
- **File:** `Analisis_Penjualan_KopiNangKau_1305003.ipynb`
- **Tujuan:** Menganalisis data penjualan untuk memahami tren penjualan, produk terlaris, dan pola pembelian guna mendukung keputusan bisnis.
- **Tools:** Python (pandas, matplotlib)
- **Temuan utama:**
  - Produk terlaris adalah Latte 
  - Penjualan tertinggi terjadi pada **April 2021**.
  - Rekomendasi: Buat paket combo pagi atau sore hari (misalnya "Coffee & Bakery Combo" yang menggabungkan Latte/Cappuccino dengan Croissant/Donat) dengan harga promosi menarik. Langkah ini efektif memicu pembelian impulsif produk makanan dan meningkatkan nilai transaksi rata-rata per pelanggan (average order value)

### 4. Financial Performance Dashboard
- **File:** `Financial Dashboard.pbix`
- **Tujuan:** Menyajikan kinerja keuangan (pendapatan, biaya, dan profit) dalam dashboard interaktif agar mudah dipantau dan dianalisis.
